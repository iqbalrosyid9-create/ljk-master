Alur penggunaan

  1. Masukkan Gemini API Key satu kali di menu Pengaturan.
  2. Pilih jumlah soal (10–60) & cetak LJK di menu Buat LJK.
  3. Atur kunci jawaban pada menu Kunci Jawaban.
  4. Siswa boleh mengisi LJK dengan bulatan penuh, tanda silang (X), atau centang (✓).
  5. Scan atau unggah foto pada menu Scanner AI, klik Analisa AI, lalu simpan.

Dua Mode Pembacaan

1. Mode AI Vision (Direkomendasikan): Membaca silang, centang, bulatan tipis, coretan ralat, dan otomatis mengisi Nama/NIS siswa.
2. Mode Cepat Lokal: Berjalan offline di browser untuk bulatan pensil 2B standar.
